# Adverbs of manner and frequency

An adverb of manner answers *how*. An adverb of frequency answers *how
often*. Both have position rules, and both have exceptions that are worth
knowing separately from the rule.

## Manner: *how*

The default position is after the verb and after its object.

> *She speaks English **fluently**.*
> *He explained the problem **clearly**.*
> *They worked **hard**.* — no object

The position moves left when the verb is a form of *be*, or when the
adverb is long and the object is short.

> *He is **very** tired.*
> *They arrived **early**.* / *They **early** arrived* — marked
> *I **very much** appreciate it.* — the adverb is fixed and takes the
> position

**With a verb of movement, the adverb comes before the verb.**

> *He **ran quickly** to the station.* ✓
> ✗ *He ran to the station quickly* — this is not wrong, and it means the
> running was for a purpose
> *She **sat down** quietly.* — before the particle
> ✗ *She sat quietly down.*

This is worth a paragraph because it is a real rule and it surprises
learners: with a phrasal verb, the adverb goes **inside** the particle.

| phrasal verb | adverb inside | adverb outside |
|---|---|---|
| *sit down* | *sit **quietly** down* | *sit down **quietly*** — marked |
| *get up* | *get **early** up* | *get up **early*** — marked |
| *turn off* | *turn **quickly** off* | *turn off **quickly*** — marked |
| *walk away* | *walk **slowly** away* | *walk away **slowly*** — acceptable |

For separable phrasal verbs the adverb goes either side of the object,
never between the verb and the particle.

> ✓ *Turn **the lights** off quickly.*
> ✓ *Turn off **the lights** quickly.*
> ✗ *Turn quickly off the lights.* — broken
> ✓ *Turn it **quickly** off.* — with a pronoun, the adverb can go in

## Frequency: *how often*

**Before the main verb, after the auxiliary.**

> *I **always** eat breakfast.*
> *I **have** always **eaten** breakfast.*
> *She **is** always **late**.*

That single pattern covers almost everything, because the adverb sits
between the auxiliary and the main verb.

> *They **have never been** to Japan.* — *have* + never + been
> *I **am** often **asked** about it.* — *am* + often + asked
> *It **has** twice **happened**.* — *has* + twice + happened

**Words of frequency, in order.**

| word | how often | example |
|---|---|---|
| *always* | 100% | *She always arrives early.* |
| *usually* | 90% | |
| *normally* | 90% | |
| *generally* | 90%, in general | |
| *often* | 70% | |
| *frequently* | 70% | |
| *often* | 70% | |
| *sometimes* | 50% | |
| *occasionally* | 30% | |
| *seldom* | 10% | |
| *rarely* | 10% | |
| *hardly ever* | almost never | |
| *never* | 0% | |

*Generally* and *usually* are not the same. *Generally* refers to what is
true in general, and it can be contradicted by a specific case. *Usually*
refers to a habit.

> *In general, prices rise in summer.* — a tendency
> *I usually walk to work.* — a habit
> ✗ *In general, I walk to work* — acceptable but less natural

<Warning>
Frequency adverbs go **before** the main verb, not after it, and this is
the single most common adverb error in learner English.

> ✓ *I **sometimes** forget.*
> ✗ *I forget **sometimes**.*

There are three genuine exceptions, and all three are fixed phrases.

> *I meet **him sometimes**.* — *meet* is intransitive here, so there is
> no object to follow the adverb
> *I go there **once in a while**.*
> *I see him **every now and then**.*

Anything with *-ly* in it can go after the verb, which is why *usually*
and *generally* are more relaxed about position than *sometimes* and
*always*.

> *I **usually** walk.* / *I walk **usually**.* — both acceptable
> *I **always** walk.* / ✗ *I walk **always**.*

*Always* and *never* are the strict ones.
</Warning>

## Definite and indefinite frequency

Some adverbs say *how often* in a particular period.

| expression | period | example |
|---|---|---|
| *once, twice, three times* | counted | *I've called twice.* |
| *once a week, twice a month* | regular | |
| *once in a while* | irregular | *Let's go out once in a while.* |
| *every day, every week* | regular | |
| *every other day* | alternating | |
| *every now and then* | irregular | |
| *now and again* | irregular | |
| *from time to time* | irregular, formal | |
| *day in, day out* | continuous | |
| *week in, week out* | continuous | |
| *once in a blue moon* | rare, idiomatic | |
| *all the time* | 100% | |
| *all day long* | continuous | |

*Every* with a singular countable noun, and the noun has to be singular.

> ✓ *every day*, *every week*, *every year*
> ✗ *every days*, *every weeks*
> ✓ *every **other** day* — alternating
> ✗ *every another day* — spoken, and wrong in writing

## *Enough* and *too*

Both take a different position from most adverbs, and both are commonly
misplaced.

**Enough** goes **after** the word it modifies, in the positive, and after
a modifier in the negative.

> *She is old **enough** to drive.* ✓
> ✗ *She is enough old to drive.*
> *He runs fast **enough**.* ✓
> *He **isn't** old **enough**.* ✓
> *He **isn't** **old enough**.* — the *not* has to come before *enough*
> ✗ *He isn't enough old.*

**Too** goes **before** the word, and *too* + adjective is followed by
*to* + base.

> *It is **too** cold **to** go out.* ✓
> ✗ *It is cold too to go out.*
> *She is **too** tired **to** work.* ✓
> *This is **too** difficult **for** me. / **too** difficult **to** do.

<DeepDive>
A set of adverbs cannot be modified by a degree word, and trying produces
errors that a learner cannot see the reason for.

**Absolute adverbs.** *already, just, still, ever, never, only, hardly,
scarcely, barely.*

> ✗ *very **just** now* → ✓ *just now*
> ✗ *very **still** here* → ✓ *still here*
> ✗ *very **ever*** → ✗ altogether
> ✗ *very **already** done* → ✓ *already done*
> ✗ *very **only** one* → ✓ *only one*

*Very* plus an absolute adverb is wrong because the adverb is already at
the limit; there is no more.

**Adverbs that take *enough* and no other degree word.** *enough, well,
far, nearly, hardly, barely, scarcely.*

> *well **enough*** ✓ / *very well* ✓
> *far **enough*** ✓ / *very far* ✓
> *nearly **enough*** — marked
> *hardly **enough*** ✓ / *very hardly* ✗

**Adverbs that take *quite, rather, fairly, pretty*.** These four are
gradable, and the ones that are not are the same four every time:
*absolutely, completely, entirely, totally, utterly, fully, perfectly,
exactly*.

> ✓ *quite cold*, *rather cold*, *fairly cold*, *pretty cold*
> ✗ *quite **totally** cold* — you cannot use two intensifiers that both
> mean *completely*
> ✓ *absolutely cold*, *completely cold*
</DeepDive>

## Four things learners get wrong about adverbs

**Frequency after the verb.** ✗ *I go always there* → ✓ *I **always**
go there.*

**An adverb splitting a phrasal verb from its particle.** ✗ *Turn
quickly off the lights.*

***Enough* before the adjective.** ✗ *She is enough old* → ✓ *old enough*.

**A degree word before an absolute adverb.** ✗ *very just now* → ✓ *just
now.*
