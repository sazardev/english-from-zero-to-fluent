# The -ed ending

The regular past ending is written *-ed* and pronounced three different
ways. A learner who says one of them for all three is understood, and
frequently understood as having a regional accent rather than a mistake,
which is why the problem survives so long.

## The three sounds

| after | sound | example |
|---|---|---|
| *-t* or *-d* | /t/ | *worked*, *passed* |
| voiceless, except *-t* | /ɪd/ | *walked*, *liked*, *jumped* |
| voiced | /d/ | *played*, *lived*, *called* |

The rule is about whether the sound before the *-ed* is voiced, and it
takes one minute to learn properly and ten years to acquire by ear.

**Voiced** means the vocal cords vibrate. *b, d, g, j, v, z, and all
vowels* are voiced. After a voiced sound, *-ed* is /d/.

> *played*, *lived*, *called*, *stayed*, *banged*, *judged*, *used*

**Voiceless** means no vibration. *p, t, k, f, s, sh, ch, th* are
voiceless. After these, *-ed* is /ɪd/, with one exception.

> *walked*, *jumped*, *laughed*, *watched*, *washed*, *asked*, *fixed*

**The exception is *-t*.** After a voiceless *t*, the *-ed* is /t/, because
two /t/ sounds in a row would be hard.

> *worked*, *walked*, *talked*, *watched*, *counted*, *wanted*

**And after a vowel or a sonorant**, the *-ed* is simply /d/.

> *played*, *decided*, *agreed*, *opened*, *needed*, *handed*, *answered*

<Warning>
The exception catches people because it is the one case where the rule
"voiceless gives /ɪd/" fails, and the failures are among the most common
words in English. *Worked, walked, talked, watched, asked, wanted,
counted, started, decided* are all /t/ or /ɪd/, never /d/.

A reliable shortcut: if the base verb ends in a *-ed* sound itself
(/t/, /d/ or /ɪd/), adding *-ed* does not change it.

> *need* /niːd/ → *needed* /ˈniːdɪd/ *(needs /ɪd/)*
> *wait* /weɪt/ → *waited* /ˈweɪtɪd/ *(needs /ɪd/)*

That does not match the *-t* rule above, and it is a genuine exception
worth learning separately: *waited* is /ɪd/, not /t/, because the base form
already ends in /t/ and adding another /t/ would give *waitt*. The
pronunciation adds a syllable instead. *Walked* is /t/ because the base ends
in /k/ and the /t/ simply releases it.
</Warning>

## Say it, do not think it

The three sounds are all the same two letters, and the letter *d* is
pronounced /d/ in exactly one of them. Writing it down does not help, so
the rule has to be spoken.

| word | base ends in | *-ed* is | why |
|---|---|---|---|
| *worked* | /k/ | /t/ | /t/ after voiceless *-t* |
| *walked* | /k/ | /t/ | same |
| *talked* | /k/ | /t/ | same |
| *watched* | /tʃ/ | /t/ | same |
| *counted* | /t/ | /ɪd/ | base already ends in /t/ |
| *wanted* | /t/ | /ɪd/ | base already ends in /t/ |
| *laughed* | /f/ | /t/ | *-ed* is /t/ after /f/ |
| *jumped* | /p/ | /t/ | same |
| *asked* | /k/ | /t/ | same |
| *washed* | /ʃ/ | /t/ | same |
| *played* | /ɪ/ | /d/ | vowel before it |
| *lived* | /v/ | /d/ | voiced |
| *called* | /d/ | /d/ | voiced |
| *stayed* | /ɪ/ | /d/ | vowel |
| *opened* | /d/ | /d/ | voiced |
| *walked* vs *talked* | /k/ | /t/ | — |

<DeepDive>
There is a regularity hiding in the exceptions, and it is worth knowing
because it predicts the cases you have not met.

**After /t/, /d/ and /ɪd/, the *-ed* is not pronounced at all.** It just
adds a syllable.

> *decide* /dɪˈsaɪd/ → *decided* /dɪˈsaɪdɪd/
> *open* /ˈəʊpən/ → *opened* /ˈəʊpənd/ *(here it is /d/, because the base
> ends in /n/, not /d/)*

**After /t/ and /d/ that is not syllable-final, the *-ed* becomes /ɪd/.**

> *paint* /peɪnt/ → *painted* /ˈpeɪntɪd/
> *need* /niːd/ → *needed* /ˈniːdɪd/
> *read* /riːd/ → *read* /red/ *(irregular in pronunciation too)*

So the practical memory aid is not the /t/ exception. It is this: **if the
base verb ends in /t/ or /d/, the *-ed* is /ɪd/. If it ends in a
voiceless consonant other than /t/, the *-ed* is /t/. If it ends in a
voiced sound or a vowel, the *-ed* is /d/.** Three cases, and the first one
covers most of the vocabulary you actually meet.
</DeepDive>

## The extra syllable

Every *-ed* past is a separate syllable, even when the *-ed* is not
pronounced. This changes the rhythm of the sentence and it is where
learners lose fluency.

> *walked* — one syllable
> *wanted* — **two** syllables, /ˈwɒntɪd/
> *needed* — **two**, /ˈniːdɪd/
> *opened* — **two**, /ˈəʊpənd/

Now put the two-syllable forms in a sentence and stress them properly.

> I *WANT*ed it. → I **WANT**ed it, stress on the first syllable.
> She *NEED*ed help. → **NEED**ed.

The stress falls on the root, never on the *-ed*. Getting this wrong makes
a learner sound robotic, and it is more noticeable than getting the sound
wrong.

## The irregular pasts that are pronounced irregularly

Some verbs are irregular in writing and in sound at the same time, and
these have to be learned.

| base | past | note |
|---|---|---|
| *read* | *read* | same spelling, different sound: /riːd/ → /red/ |
| *lead* | *led* | /liːd/ → /led/ |
| *deal* | *dealt* | /diːl/ → /delt/, no /d/ |
| *feel* | *felt* | /fiːl/ → /felt/ |
| *keep* | *kept* | same |
| *leave* | *left* | /liːv/ → /left/ |
| *lose* | *lost* | /luːz/ → /lɒst/ |
| *mean* | *meant* | /miːn/ → /ment/ |
| *say* | *said* | /seɪ/ → /sed/, and said does not end in /d/ |
| *send* | *sent* | same |
| *spend* | *spent* | same |
| *build* | *built* | /bɪld/ → /bɪlt/ |
| *send* | *sent* | /send/ → /sent/ |

<Warning>
*Said* is the one to watch. It does not end in /d/. It ends in /ɛd/, and
the *-ed* is folded into the vowel.

> *said* /sɛd/ — one syllable, and the vowel is short

The same is true of a small group: *paid* /peɪd/, *laid*, *made* /meɪd/,
*told*. All of them drop the /d/. If you say /seɪd/ for *said*, a listener
hears a different word, because /seɪd/ is not a word in English.
</Warning>

## Four things learners get wrong about -ed

**Saying /d/ for everything.** ✗ /wɒkd/ → ✓ /wɒkt/.

**Saying /ɪd/ after *-t*.** ✗ /wɔːtɪd/ for *wanted* is right, but
/wɒkɪd/ for *worked* is wrong.

**Adding a syllable where there is none.** ✗ *wanted* as one syllable.

**Saying *said* as /seɪd/.** It is /sɛd/, and the other is a different
word.
